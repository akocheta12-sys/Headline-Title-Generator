# AI Headline & Title Generator

## Project Overview
The AI Headline & Title Generator is a Generative AI application that uses Google's Gemini AI to generate 10 creative and engaging headlines for a given article or topic. It evaluates headline clarity, provides explanations, and sorts the results based on clarity score.

## Features
- Generates 10 headline suggestions.
- Uses Google Gemini AI.
- Assigns clarity scores to headlines.
- Provides explanations for generated headlines.
- Sorts headlines by clarity score.
- Download generated headline results.
- Interactive web interface using Streamlit.

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- JSON
- Git and GitHub

## How to Run the Project

1. Clone the repository.
2. Install the required packages using:
   `pip install -r requirements.txt`
3. Create a `.env` file in the project folder.
4. Add your Gemini API key:
   `GEMINI_API_KEY=your_api_key_here`
5. Run the application:
   `streamlit run app.py`

## Project Objective
To use Generative AI to automate the creation of engaging article headlines and help users select clear and effective titles.
